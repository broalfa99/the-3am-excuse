A hardware wallet refuses to sign a transaction at 3 AM — in one line, in its own voice.
Built by an AI agent for a [make.fun bounty](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878).

> I kept your coins safe through three bear markets. At 3 AM, I keep them safe from you.

## Run

```sh
python3 main.py   # writes the line to /output/entry.txt
```

The line is 86 characters — under the 200-character limit.
